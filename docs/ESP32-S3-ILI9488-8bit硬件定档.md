# ESP32-S3 + ILI9488 硬件定档说明

> 状态：**8bit 8080 并口方案已定档**；电源 / RTC 已定档  
> 更新日期：2026-11-12  
> 说明：本文先锁定元器件与引脚；PCB、按键、软件细节等后续补充。

---

## 1. 方案结论

| 项目 | 定档 |
|------|------|
| 显示接口 | **8080 I80，8bit**（不做 16bit） |
| 主控 | ESP32-S3，**必须带 PSRAM**（N8R8 / N16R8） |
| 分辨率 | 480 × 320，RGB565 |
| 电源 | **TP4056 充电 + SY8089 降压 3.3V** |
| 开关机 | **分立机械开关**（切断 SY8089 输入，不占 MCU 脚） |
| RTC | **RX8900CE**（与 GT911 共用 I2C） |
| 音量调节 | **电位器 + ADC**（不用旋转编码器） |
| IO 扩展 | **暂不上 TCA9555**；按键先直连主控 |
| 目标用途 | LVGL 控制面板为主；本地/网络视频为辅（MJPEG 级） |

**选型理由（简要）：**

- 相对 SPI：刷新明显更好，LVGL 可用。
- 相对 16bit：少占 8 根 IO，布线简单；480×320 UI / MJPEG 场景带宽通常够用。
- 16bit 在 S3 上连续合法脚紧张，外设一多容易顶满，性价比不高。

## 2. 元器件定档

### 2.1 已定档

| 类别 | 型号 / 规格 | 备注 |
|------|-------------|------|
| 主控模组 | ESP32-S3-N8R8 或 ESP32-S3-N16R8 | 必须 Octal PSRAM；优先模组方案 |
| 显示屏 | 耀元鸿 3.5" TFT，驱动 IC **ILI9488** | 并口/串口可选款；本方案走并口 |
| 屏接口模式 | **8bit 8080** | 硬件：焊 **R8**，拆 **R16**（以丝印为准） |
| 触摸 | **GT911** 5 点电容 | 与电阻触摸互斥，只保留电容侧 0Ω |
| 麦克风 | **ZTS6672**（I2S MEMS） | 数字麦，抗干扰较好 |
| 功放 | **NS4168**（I2S 输入） | 与麦共享 BCLK/LRCLK |
| 存储 | MicroSD，**SPI 模式** | 不用 SDMMC（避免和 Flash/PSRAM 脚冲突） |
| 充电管理 | **TP4056** | USB 5V 充锂电池；读 CHRG# / STDBY# |
| 系统降压 | **SY8089** | 开关之后 → **3.3V** 系统电 |
| 开关机 | **机械拨动 / 翘板开关（SPST）** | 分立硬开关；串在电池到 SY8089 VIN 之间 |
| RTC | **RX8900CE** | I2C 地址 `0x32`；可断电计时（需备用电，细节后续补） |
| 音量电位器 | 单圈电位器（建议 **10k** 线性 B 型） | 一端 3.3V、一端 GND、中心抽头进 ADC |

**音量为什么用电位器（定档说明）：**

- 音量是绝对量，电位器位置即音量，掉电后旋钮位置仍在，体验自然。
- 接线只需 1 个 ADC 脚；旋转编码器要 A/B（+SW）更吃 IO，还要防抖/计数。
- 本方案剩余 ADC 脚紧张，电位器更合适；编码器留给以后「菜单翻页」之类相对操作（若需要）。

**电源拓扑（定档）：**

```text
USB 5V ──► TP4056 ──► 锂电池
                         │
                         ▼
                    机械开关机（SPST）
                         │
                         ▼
                      SY8089 ──► 3.3V ──► ESP32-S3 / 屏 / 外设
```

**开关机策略：**

- 开关切断的是 **SY8089 输入（电池→降压）**，不是 USB→TP4056。
- **关机后**：3.3V 整机掉电（S3 / 屏 / 音频全灭）；插 USB 仍可经 TP4056 给电池充电。
- **不占用 GPIO**，不做长按软开关。
- SY8089 EN：有 VIN 时硬件使能即可（EN 可经电阻接到 VIN/使能脚），由机械开关间接控制上下电。

> 具体二极管或-ing、输入切换、电池规格在原理图阶段补充；芯片与开关策略以本节为准。

## 3. 引脚定档

### 3.1 保留脚（禁止挪用）

| GPIO | 用途 | 说明 |
|------|------|------|
| 19, 20 | USB D− / D+ | 保留 USB 下载 / JTAG |
| 43, 44 | UART0 TX / RX | 保留串口下载与日志 |
| 33–37 | Flash / PSRAM | N8R8、N16R8 模组占用，不可当普通 IO |
| 0 | BOOT / Strapping | 可留作 Boot 键；慎作强拉输入 |

> ESP32-S3 **无 GPIO22 / 23 / 24 / 25**，原理图勿再出现这些脚。

### 3.2 显示屏 ILI9488（I80 8bit）

|------|------|------|
| D0 | 10 | 数据线，必须连续 |
| D1 | 11 | |

| D3 | 13 | |
| D4 | 14 | |
| D5 | 15 | |
| D6 | 16 | |
| D7 | 17 | |

| DC | 8 | 命令/数据 |
| CS | 9 | 片选 |
| RST | 21 | 复位 |
| BL | 7 | 背光（可 PWM） |

### 3.3 I2C 总线（GT911 + RX8900CE 共用）

| 信号 | GPIO | 说明 |
|------|------|------|
| SDA | 1 | 共用 I2C 数据 |
| SCL | 2 | 共用 I2C 时钟 |

**GT911**

| 信号 | GPIO | 说明 |
|------|------|------|
| INT | 4 | 中断；上电电平决定地址 |
| RST | 5 | 复位 |

地址说明：

- 上电 INT 拉高 → 常见 `0x5D`
- 上电 INT 拉低 → 常见 `0x14`
- 软件地址必须与硬件一致，否则触摸无数据

**RX8900CE**

| 信号 | GPIO | 说明 |
|------|------|------|
| SDA / SCL | 1 / 2 | 挂同一条 I2C，地址 **`0x32`** |
| INT / FOUT | 6 | 闹钟 / 定时中断（低有效，需上拉） |

> I2C 上拉建议 4.7k 到 3.3V。总线设备：GT911 + RX8900CE，地址不冲突。

### 3.4 电源与开关机（TP4056 / SY8089 / 机械开关）

| 信号 | GPIO | 说明 |
|------|------|------|
| TP4056 CHRG# | 47 | 充电中拉低（开漏，需上拉到 3.3V）；仅开机且 3.3V 存在时可被 MCU 读取 |
| TP4056 STDBY# | 48 | 充满拉低（开漏，需上拉到 3.3V）；同上 |
| SY8089 EN | — | 不接 MCU；有 VIN 时硬件使能 |
| 开关机 | — | **机械 SPST**，串在「电池正极 → SY8089 VIN」；不占 GPIO |

> 关机后 MCU 无法读充电状态灯脚——属预期行为；若关机也要指示充电，用 TP4056 外接 LED（CHRG/STDBY 本身常带灯）即可，不必进 MCU。

### 3.5 音量电位器（ADC）

| 信号 | GPIO | 说明 |
|------|------|------|
| VOL_ADC | 3 | **ADC1_CH2**；电位器中心抽头 |

接线：

```text
3.3V ---- 电位器一端
GND  ---- 电位器另一端
GPIO3 --- 中心抽头 ----(串 1k)----+---- ADC
                                 |
                               104 到地（可选滤波，勿用大电容）
```

注意：

- GPIO3 是 strapping：上电后可作 ADC；**不要**在抽头上挂大电容（≥1µF），避免上电电平拖泥带水。
- 属 ADC1，与 Wi‑Fi 可同时用。
- 量程 0～3.3V；软件做均值滤波 + 死区，避免抖动改音量。
- 剩余脚 `30/31/32` **没有 ADC**，不能拿来接电位器。

### 3.6 音频（ZTS6672 + NS4168，I2S 共享时钟）

## 4. 电气与装配要点（已确认）

1. **逻辑电平一律 3.3V**；屏模组即使标 5V 供电，数据线仍按 3.3V 处理，勿直接灌 5V 逻辑。
2. 屏必须切到 **8bit**：电阻错误会导致花屏、乱码。
3. 电容触摸 / 电阻触摸焊点互斥，只保留 GT911 一侧。
4. 数据线尽量短；面包板阶段时钟先从 **20MHz** 起，稳定后再试 30/40MHz。
5. LVGL / 全屏缓冲需要 PSRAM；无 PSRAM 不要按本方案做。
6. **TP4056**：充电电流电阻按电池规格选；CHRG# / STDBY# 开漏，上拉到 3.3V 后再进 GPIO。
7. **SY8089**：FB 分压整定 **3.3V**；输入由机械开关控制；EN 随 VIN 硬件使能；输入输出就近陶瓷电容按手册摆放。
8. **分立开关机**：开关额定电流需大于整机峰值（屏背光 + S3 + 功放）；优先切电池正，GND 常连。
9. **RX8900CE**：与 GT911 共 I2C；主电被开关切断后，若无备用电则 RTC 停走——备用电方案仍待补。
10. **音量电位器**：建议 10k 线性；中心抽头串 1k 进 GPIO3；可并联 104 滤波，避免大电容。

## 5. 软件方向（暂记，细节后续补充）

| 项 | 倾向 |
|----|------|
| 框架 | ESP-IDF 5.x |
| 显示 | `esp_lcd` I80 + ILI9488 panel |
| 触摸 | `esp_lcd_touch_gt911` |
| RTC | RX8900CE I2C 驱动（地址 `0x32`） |
| 电源状态 | 读 GPIO47/48 判断充电中 / 充满 |
| 音量 | ADC1_CH2（GPIO3）采样 → 映射功放/软件音量；均值 + 死区 |
| UI | LVGL，draw buffer 放 PSRAM |
| 音频 | I2S 全双工（录音 + 播放） |
| 存储 | SPI SD 驱动 |
| 视频 | 以 MJPEG 为主；不做通用 H.264 网播目标 |
