# ESP32-S3 + ILI9488 硬件定档说明

> 状态：**8bit 8080 并口方案已定档**  
> 更新日期：2026-11-12  
> 说明：本文先锁定元器件与引脚；电源、PCB、软件细节等后续补充。

---

## 1. 方案结论

| 项目 | 定档 |
|------|------|
| 显示接口 | **8080 I80，8bit**（不做 16bit） |
| 主控 | ESP32-S3，**必须带 PSRAM**（N8R8 / N16R8） |
| 分辨率 | 480 × 320，RGB565 |
| IO 扩展 | **暂不上 TCA9555**；按键/编码器先直连主控 |
| 目标用途 | LVGL 控制面板为主；本地/网络视频为辅（MJPEG 级） |

**选型理由（简要）：**

- 相对 SPI：刷新明显更好，LVGL 可用。
- 相对 16bit：少占 8 根 IO，布线简单；480×320 UI / MJPEG 场景带宽通常够用。
- 16bit 在 S3 上连续合法脚紧张，外设一多容易顶满，性价比不高。

## 2. 元器件定档

### 2.1 已定档

| 类别 | 型号 / 规格 | 备注 |
|------|-------------|------|
| 主控模组 | ESP32-S3-N8R8 或 ESP32-S3-N16R8 | 必须 Octal PSRAM；优先模组方案 |
| 显示屏 | 耀元鸿 3.5" TFT，驱动 IC **ILI9488** | 并口/串口可选款；本方案走并口 |
| 屏接口模式 | **8bit 8080** | 硬件：焊 **R8**，拆 **R16**（以丝印为准） |
| 触摸 | **GT911** 5 点电容 | 与电阻触摸互斥，只保留电容侧 0Ω |
| 麦克风 | **ZTS6672**（I2S MEMS） | 数字麦，抗干扰较好 |
| 功放 | **NS4168**（I2S 输入） | 与麦共享 BCLK/LRCLK |
| 存储 | MicroSD，**SPI 模式** | 不用 SDMMC（避免和 Flash/PSRAM 脚冲突） |

| 按键 / 编码器 | 待定 | 优先使用剩余 GPIO 直连 |
| 电池 / 充电 | 待定 | — |

## 3. 引脚定档

### 3.1 保留脚（禁止挪用）

| GPIO | 用途 | 说明 |
|------|------|------|
| 19, 20 | USB D− / D+ | 保留 USB 下载 / JTAG |
| 43, 44 | UART0 TX / RX | 保留串口下载与日志 |
| 33–37 | Flash / PSRAM | N8R8、N16R8 模组占用，不可当普通 IO |
| 0 | BOOT / Strapping | 可留作 Boot 键；慎作强拉输入 |

### 3.3 触摸 GT911（独立 I2C）

| 信号 | GPIO | 说明 |
|------|------|------|
| SDA | 1 | I2C 数据 |
| SCL | 2 | I2C 时钟 |
| INT | 4 | 中断；上电电平决定地址 |
| RST | 5 | 复位 |

地址说明：

- 上电 INT 拉高 → 常见 `0x5D`
- 上电 INT 拉低 → 常见 `0x14`
- 软件地址必须与硬件一致，否则触摸无数据

## 4. 电气与装配要点（已确认）

1. **逻辑电平一律 3.3V**；屏模组即使标 5V 供电，数据线仍按 3.3V 处理，勿直接灌 5V 逻辑。
2. 屏必须切到 **8bit**：电阻错误会导致花屏、乱码。
3. 电容触摸 / 电阻触摸焊点互斥，只保留 GT911 一侧。
4. 数据线尽量短；面包板阶段时钟先从 **20MHz** 起，稳定后再试 30/40MHz。
5. LVGL / 全屏缓冲需要 PSRAM；无 PSRAM 不要按本方案做。
