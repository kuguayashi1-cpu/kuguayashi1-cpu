# ESP32-S3 + ILI9488 硬件定档说明

> 状态：**8bit 8080 并口方案已定档**；电源 / RTC / GPIO 软开关机已定档  
> 更新日期：2026-11-12  
> 说明：本文先锁定元器件与引脚；PCB、按键、软件细节等后续补充。

---

## 1. 方案结论

| 项目 | 定档 |
|------|------|
| 显示接口 | **8080 I80，8bit**（不做 16bit） |
| 主控 | ESP32-S3，**必须带 PSRAM**（N8R8 / N16R8） |
| 分辨率 | 480 × 320，RGB565 |
| 电源 | **TP4056 充电 + SY8089 降压 3.3V** |
| 开关机 | **分立软开关机**（按键开机 + **GPIO 维持/关机**，控 SY8089 EN） |
| RTC | **RX8900CE**（与 GT911 共用 I2C） |
| 音量调节 | **电位器 + ADC**（不用旋转编码器） |
| IO 扩展 | **暂不上 TCA9555**；按键先直连主控 |
| 目标用途 | LVGL 控制面板为主；本地/网络视频为辅（MJPEG 级） |

**选型理由（简要）：**

- 相对 SPI：刷新明显更好，LVGL 可用。
- 相对 16bit：少占 8 根 IO，布线简单；480×320 UI / MJPEG 场景带宽通常够用。
- 16bit 在 S3 上连续合法脚紧张，外设一多容易顶满，性价比不高。

## 2. 元器件定档

### 2.1 已定档

| 类别 | 型号 / 规格 | 备注 |
|------|-------------|------|
| 主控模组 | ESP32-S3-N8R8 或 ESP32-S3-N16R8 | 必须 Octal PSRAM；优先模组方案 |
| 显示屏 | 耀元鸿 3.5" TFT，驱动 IC **ILI9488** | 并口/串口可选款；本方案走并口 |
| 屏接口模式 | **8bit 8080** | 硬件：焊 **R8**，拆 **R16**（以丝印为准） |
| 触摸 | **GT911** 5 点电容 | 与电阻触摸互斥，只保留电容侧 0Ω |
| 麦克风 | **ZTS6672**（I2S MEMS） | 数字麦，抗干扰较好 |
| 功放 | **NS4168**（I2S 输入） | 与麦共享 BCLK/LRCLK |
| 存储 | MicroSD，**SPI 模式** | 不用 SDMMC（避免和 Flash/PSRAM 脚冲突） |
| 充电管理 | **TP4056** | USB 5V 充锂电池；读 CHRG# / STDBY# |
| 系统降压 | **SY8089** | 电池常接 VIN；**EN 做开关机** → **3.3V** |
| 电源键 | **6×6 轻触开关**（无锁） | 按一下拉高 EN 开机；也可软件检测长按请求关机 |
| 开关机分立件 | **1N4148×2 + 电阻** | 按键 / GPIO 二极管或，维持 EN；见拓扑 |
| RTC | **RX8900CE** | I2C 地址 `0x32`；可断电计时（需备用电，细节后续补） |
| 音量电位器 | 单圈电位器（建议 **10k** 线性 B 型） | 一端 3.3V、一端 GND、中心抽头进 ADC |

**音量为什么用电位器（定档说明）：**

- 音量是绝对量，电位器位置即音量，掉电后旋钮位置仍在，体验自然。
- 接线只需 1 个 ADC 脚；旋转编码器要 A/B（+SW）更吃 IO，还要防抖/计数。
- 本方案剩余 ADC 脚紧张，电位器更合适；编码器留给以后「菜单翻页」之类相对操作（若需要）。

**电源拓扑（定档）：**

```text
USB 5V ──► TP4056 ──► 锂电池 ──► SY8089 VIN（常接）
                                   │
                                   ├─ EN ←── 二极管或 ──┬── 电源键 → 电池正极（点按开机）
                                   │                    └── GPIO32 PWR_HOLD（开机后拉高维持）
                                   │
                                   └─ 3.3V ──► ESP32-S3 / 屏 / 外设
                                         ▲
                                         └── GPIO31 PWR_KEY（读按键，可选长按关机）
```

**GPIO 软开关机策略（定档）：**

1. **默认关机**：EN 经 **100k 下拉** 到 GND，SY8089 关闭，3.3V 掉电；USB 仍可经 TP4056 充电。
2. **开机**：按电源键 → 经二极管把 EN 拉到电池高电平 → SY8089 出 3.3V → S3 启动。
3. **维持**：`app_main` 最早把 **GPIO32（PWR_HOLD）置高**（经二极管/电阻到 EN）→ 松手后仍保持开机。
4. **关机**：软件收尾后把 **GPIO32 拉低** → EN 掉下 → 整机断电。  
   也可长按电源键：GPIO31 检测到长按 → 走同一关机流程。
5. **不是**船型硬切断干路；电流不经过轻触开关，开关只控 EN（µA～mA 级）。

**开关机物料推荐：**

| 用途 | 型号 | 说明 |
|------|------|------|
| 电源键 | **6×6×5 轻触开关**（四脚贴片/插件均可） | 无锁点动 |
| 或门二极管 | **1N4148** ×2 | 按键一路 + PWR_HOLD 一路；也可用 BAT54C 双管 |
| EN 下拉 | **100k** | 保证松手且 HOLD=0 时关断 |
| HOLD 限流 | **1k～10k** | GPIO32 → 二极管阳极 |

> 若以后要更低关机漏电，可再加 P-MOS（如 AO3401）切 VIN；首版先用 **EN 控制**，电路最简单。

## 3. 引脚定档

### 3.1 保留脚（禁止挪用）

| GPIO | 用途 | 说明 |
|------|------|------|
| 19, 20 | USB D− / D+ | 保留 USB 下载 / JTAG |
| 43, 44 | UART0 TX / RX | 保留串口下载与日志 |
| 33–37 | Flash / PSRAM | N8R8、N16R8 模组占用，不可当普通 IO |
| 0 | BOOT / Strapping | 可留作 Boot 键；慎作强拉输入 |

> ESP32-S3 **无 GPIO22 / 23 / 24 / 25**，原理图勿再出现这些脚。

### 3.2 显示屏 ILI9488（I80 8bit）

|------|------|------|
| D0 | 10 | 数据线，必须连续 |
| D1 | 11 | |
| D2 | 12 | |
| D3 | 13 | |
| D4 | 14 | |
| D5 | 15 | |
| D6 | 16 | |
| D7 | 17 | |
| WR | 18 | 写时钟 |
| DC | 8 | 命令/数据 |
| CS | 9 | 片选 |
| RST | 21 | 复位 |
| BL | 7 | 背光（可 PWM） |

### 3.3 I2C 总线（GT911 + RX8900CE 共用）

| 信号 | GPIO | 说明 |
|------|------|------|
| SDA | 1 | 共用 I2C 数据 |
| SCL | 2 | 共用 I2C 时钟 |

**GT911**

| 信号 | GPIO | 说明 |
|------|------|------|
| INT | 4 | 中断；上电电平决定地址 |
| RST | 5 | 复位 |

地址说明：

- 上电 INT 拉高 → 常见 `0x5D`
- 上电 INT 拉低 → 常见 `0x14`
- 软件地址必须与硬件一致，否则触摸无数据

**RX8900CE**

| 信号 | GPIO | 说明 |
|------|------|------|
| SDA / SCL | 1 / 2 | 挂同一条 I2C，地址 **`0x32`** |
| INT / FOUT | 6 | 闹钟 / 定时中断（低有效，需上拉） |

> I2C 上拉建议 4.7k 到 3.3V。总线设备：GT911 + RX8900CE，地址不冲突。

### 3.4 电源与 GPIO 开关机（TP4056 / SY8089 EN）

| 信号 | GPIO | 说明 |
|------|------|------|
| TP4056 CHRG# | 47 | 充电中拉低（开漏，上拉到 3.3V） |
| TP4056 STDBY# | 48 | 充满拉低（开漏，上拉到 3.3V） |
| PWR_HOLD | **32** | **输出**；高=维持 SY8089 EN；低=关机 |
| PWR_KEY | **31** | **输入**（上拉）；读电源键，用于长按关机 / UI |
| SY8089 EN | — | 按键与 GPIO32 二极管或后接入；100k 下拉 |

开机软件要点：上电后 **立刻** `PWR_HOLD=1`，再初始化其它外设；关机前先存状态，再 `PWR_HOLD=0`。

### 3.5 音量电位器（ADC）

| 信号 | GPIO | 说明 |
|------|------|------|
| VOL_ADC | 3 | **ADC1_CH2**；电位器中心抽头 |

接线：

```text
3.3V ---- 电位器一端
GND  ---- 电位器另一端
GPIO3 --- 中心抽头 ----(串 1k)----+---- ADC
                                 |
                               104 到地（可选滤波，勿用大电容）
```

注意：

- GPIO3 是 strapping：上电后可作 ADC；**不要**在抽头上挂大电容（≥1µF），避免上电电平拖泥带水。
- 属 ADC1，与 Wi‑Fi 可同时用。
- 量程 0～3.3V；软件做均值滤波 + 死区，避免抖动改音量。
- 剩余数字脚里 **没有 ADC** 的不要拿来接电位器。

### 3.6 音频（ZTS6672 + NS4168，I2S 共享时钟）

## 4. 电气与装配要点（已确认）

1. **逻辑电平一律 3.3V**；屏模组即使标 5V 供电，数据线仍按 3.3V 处理，勿直接灌 5V 逻辑。
2. 屏必须切到 **8bit**：电阻错误会导致花屏、乱码。
3. 电容触摸 / 电阻触摸焊点互斥，只保留 GT911 一侧。
4. 数据线尽量短；面包板阶段时钟先从 **20MHz** 起，稳定后再试 30/40MHz。
5. LVGL / 全屏缓冲需要 PSRAM；无 PSRAM 不要按本方案做。
6. **TP4056**：充电电流电阻按电池规格选；CHRG# / STDBY# 开漏，上拉到 3.3V 后再进 GPIO。
7. **SY8089**：VIN 常接电池；FB=3.3V；**EN 做开关机**；注意 EN 阈值阈值与手册一致。
8. **GPIO 开关机**：按键只拉 EN，不走大电流；`PWR_HOLD` 必须在启动早期置位，否则松手掉电。
9. **RX8900CE**：与 GT911 共 I2C；关机后无备用电则 RTC 停走——备用电仍待补。
10. **音量电位器**：建议 10k 线性；中心抽头串 1k 进 GPIO3；可并联 104 滤波，避免大电容。

## 5. 软件方向（暂记，细节后续补充）

| 项 | 倾向 |
|----|------|
| 框架 | ESP-IDF 5.x |
| 显示 | `esp_lcd` I80 + ILI9488 panel |
| 触摸 | `esp_lcd_touch_gt911` |
| RTC | RX8900CE I2C 驱动（地址 `0x32`） |
| 电源状态 | 读 GPIO47/48 判断充电中 / 充满 |
| 开关机 | 启动即 `GPIO32=1`；关机 `GPIO32=0`；`GPIO31` 长按触发关机流程 |
| 音量 | ADC1_CH2（GPIO3）采样 → 映射功放/软件音量；均值 + 死区 |
| UI | LVGL，draw buffer 放 PSRAM |
| 音频 | I2S 全双工（录音 + 播放） |
| 存储 | SPI SD 驱动 |
| 视频 | 以 MJPEG 为主；不做通用 H.264 网播目标 |
